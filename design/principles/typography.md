# 字体与文字层级

## 基本原则

字体应帮助用户快速判断信息的重要程度。字号、字重、行高和颜色共同构成层级，不应依赖单纯放大字体。

## 建议

- 建立少量稳定的文字类型：页面标题、区块标题、正文、说明文字、标签。
- 常规 Web 应用的正文可优先考虑 **14–16px**；密集后台可以因场景调整。
- 标题、正文、辅助文字应有清晰区别，但不要为每条文本定义新的字号。
- 长段正文保证舒适行高；数字与数据表格注意对齐。
- 重点信息优先通过位置、字重和内容组织强调，避免全页面大量加粗。
- 辅助文字可以降低视觉权重，但要满足可读性与对比度要求。

## 示例层级（仅供参考）

| 类型 | 字号示例 | 常见用途 |
| --- | --- | --- |
| 页面标题 | 24px | 页面一级标题 |
| 区块标题 | 18–20px | 内容区块 |
| 正文 | 14–16px | 主要信息、表单 |
| 辅助文字 | 12–14px | 时间、说明、备注 |

使用项目已有字号 token 时，以现有定义为准。

## 常见问题

- 同一页面出现大量无规律的字号。
- 将重要信息仅用颜色表示，缺少其他视觉层级。
- 辅助文字过小或过淡，导致难以阅读。
- 标题和正文之间缺少足够的区分。
