# 间距系统

## 适用场景

Web 应用、管理后台、表单、卡片、弹窗和组件库。

## 基本原则

采用 **8px 为主、4px 为辅**的间距体系，尽量从一组固定值中选择，减少页面中互不协调的间距。

推荐常用值：

`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64px`

这是一套可调整的建议，不代表每个尺寸都必须是 8 的倍数。

## 使用建议

| 场景 | 可参考的间距 |
| --- | --- |
| 图标与文字、紧凑元素之间 | 4–8px |
| 组件内部元素 | 8–12px |
| 卡片内边距 | 16–24px |
| 表单项、内容组之间 | 16–24px |
| 页面主要区域之间 | 24–32px |
| 大区块或页面留白 | 32–64px |

优先按内容关系决定间距：同一组信息应更靠近，不同组之间应留出更明显的距离。相同用途的组件应保持统一的内边距与间距。

## 不要机械使用

- 字体大小、行高、边框宽度、图标尺寸，不要求全部是 8 的倍数。
- 14px 正文、1px 边框、20px 图标、12px 内边距均可以合理存在。
- 密集表格、移动端、小尺寸组件应根据可用空间灵活处理。
- 已有组件库提供了 spacing token 时，优先使用项目现有值。

## AI 设计检查

- 是否出现许多无明确理由的间距数值？
- 同类型卡片、表单是否使用统一的内边距？
- 内容分组关系是否可以仅通过间距看清？
- 缩小窗口后是否发生拥挤或错位？
