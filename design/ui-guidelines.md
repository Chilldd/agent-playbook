# UI 设计规范

## 核心原则

- **清晰**：优先让用户看懂信息、找到操作，不为了视觉效果增加无用元素。
- **一致**：同一产品中的布局、文字、颜色和组件遵循统一规则。
- **有层次**：通过位置、分组、间距和文字突出重点，而不是依赖大量装饰。
- **适合场景**：数据密集型后台重视效率，展示型页面可以增加留白；不要套用同一种布局。

## 布局与间距

- 建立统一的间距尺度，可采用 **8px 为主、4px 为辅**的体系，具体数值按项目调整。
- 有关联的内容放在一起，不同内容组之间保持明显距离。
- 同级元素统一对齐，重复区域保持一致的边距和排列方式。
- 避免随意设置宽高和固定位置，兼顾不同屏幕尺寸及长文本。

## 排版与颜色

- 区分页面标题、区块标题、正文和辅助信息，控制字号与字重的种类。
- 优先保证文字可读：字号、行高和颜色对比度合理，避免过小或过淡。
- 颜色应有明确用途：主色用于强调操作，状态色用于提示结果，中性色承担大部分界面。
- 圆角、边框、阴影保持统一；渐变、模糊等效果按需要使用，不喧宾夺主。

## 组件与交互

- 优先使用项目现有组件和主题变量，避免重复设计相同功能。
- 相同用途的按钮、输入框、卡片和弹窗保持统一的外观与操作方式。
- 重要操作容易识别；提供必要的悬停、焦点、禁用、加载、成功和错误反馈。
- 考虑空数据、异常、超长内容等实际情况，不只设计正常状态。

## 完成前检查

- 主要信息和操作是否一眼可见？
- 间距、对齐、字体、颜色和组件是否一致？
- 文字是否清楚，交互反馈是否明确？
- 不同屏幕尺寸及异常状态下是否仍然可用？

> 具体数值与风格以项目现有设计系统为准；以上规则用于指导和检查，不要求机械套用。
